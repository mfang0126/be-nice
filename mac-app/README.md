# mac-app

Swift + AppKit menu bar app (LSUIElement). No App Sandbox (required for cross-app Accessibility).

- `AXProbe` — M0 cross-app read/write probe (fixed test text, no LLM).
- `WriteBack` — write-back state machine + target revalidation (M1).
- `OverlayDot` — nonactivating NSPanel, becomesKeyOnlyIfNeeded (M3).
